Shopee Monthly Sales Report

An internal, single-seller automation tool for my own Shopee shop.

What it does

  • Runs as a scheduled job once a month (no login or user accounts needed).
  • Reads my own shop's completed orders, order details and escrow fee details through the Shopee Open Platform API.
  • Generates an Excel (.xlsx) report: product, quantity, selling price, buying price and Shopee fees.
  • Sends the report to me through a private Telegram bot for bookkeeping and invoicing.

Data & privacy

  • Read-only: it never changes products, stock or orders.
  • No buyer personal information (name, address, phone) is requested or stored.
  • Data is not shared with any third party.

Interface

There is no web interface. The tool's output is an Excel file delivered via Telegram.
